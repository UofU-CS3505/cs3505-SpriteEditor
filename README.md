# Sprite Editor

A C++ and Qt-based desktop sprite editor application developed as a collaborative team project for CS 3505 at the University of Utah

## Features

* **Drawing & Editing Tools:** Includes a pen, brush, eraser, custom color options, and color replacement functionality.
* **Frame Management:** Create, organize, and preview frame-by-frame sprite animations.
* **Project Management:** Save, load, and export projects seamlessly with custom UI icons.
* **History Support:** Full undo and redo capabilities to streamline the pixel art creation workflow.
* **Preview Options:** Real-size preview window to inspect sprites at their actual dimensions.
